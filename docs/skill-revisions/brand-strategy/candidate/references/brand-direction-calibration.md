# Brand direction calibration

Use this before generating or screening umbrella/studio names.

## Three-axis gate

Calibrate these independently:

1. **Language:** English, Turkish-rooted, founder-led, or language-neutral.
2. **Originality mechanism:** dictionary word, natural English compound, semantically legible derivation, or fully invented word.
3. **Tone:** balanced/neutral, sharp/technical, warm/creative, or bold/experimental.

“Original and international” is not enough direction. It can produce two opposite failures: pseudo-mythic invented words or generic combinations of broad business words.

## Correction handling

User corrections become hard constraints for the rest of that naming track:

- **Too mythological/mystical:** drop fantasy phonetics such as repeated `-ora`, `-enya`, `-ryn`, and `-lune` patterns.
- **Not original / too generic:** drop predictable `Plain+Works`, `Open+Matter`, `Base+Work`-style compounds.
- **English name required:** do not pivot to Turkish roots, even when they are globally pronounceable.

Do not ask the user to repeat a constraint they already supplied.

## Efficient sequence

1. Reuse the user's stated language, structure and tone. Ask only when missing direction materially changes the result.
2. If direction is genuinely open, show a small set of **direction seeds**, clearly distinct from screened candidates.
3. Generate candidates at the requested scale; do not impose a fixed quota or require another approval when the brief is already clear.
4. Apply pronunciation and lightweight collision filters internally. If domain feasibility is a delivery requirement, check the exact approved domain pattern before presentation.
5. Present the requested quality shortlist or longlist; reserve deeper social/trademark checks for finalists unless the user requested them earlier.

This avoids spending registry-search effort on a naming region the user dislikes and avoids making the user reject obviously conflicting names.
